# 架构与状态来源

## 渲染与状态

机械馆使用 JavaScript 计算的等距投影与 SVG 绘制，不使用 WebGL。共用核心负责投影、形状、视角输入、逐帧调度和 UI。各 scene 自己维护实际动作状态；观察面板、读数与高亮从这些状态派生，不另造一套动画。

`object-collection/dist/shell.js` 是十展品目录和 hash 路由；`home.js`、`home.css` 与 `previews/*.svg` 组成首页。馆内七件注册在 `scenes/`。`elevator-occlusion.js` 解决电梯实体可见性与深度关系，不能删除或调换加载顺序。

洗衣机、风扇、抓娃娃机保留独立页面：洗衣机与抓物页面含内联渲染基础；风扇使用独立 Paper3D 引擎。为了避免迁移引入画面或事件回归，本次不强行抽取成单一引擎或单份公共脚本。

## 十件各自的状态职责

- 咖啡：装豆、研磨、锁柄、杯子、杯量、冲煮暂停、倒奶、取杯；可选分步观察从真实状态事件完成。
- 八音盒：盒盖、发条能量、滚筒与拨齿；观察模式复用同一转角。
- 售货机：投币、库存、购买、主动卡货示范、安全复位、继续/退款；钱和库存守恒。
- 面包机：装入、压杆、加热、弹起、领取；移动面包与顶板关系由现有分面逻辑处理。
- 唱片机：盘速、抬臂、移臂、落针、播放与归位；托架间隙不可只靠绘制排序替代。
- 拍立得：快门、滚轮、走纸、显影、收藏与补纸；内部小图来自实际相位。
- 电梯：楼层队列、关门、行驶、平层、开门和联锁；跨阶段余量由状态机消费。
- 洗衣机：装衣、舱门、进水/转筒/排水与取衣；其动画是简化示意，不宣称真实流体。
- 风扇：档位、转速/累计转角、摇头、关机惯性；按解析时间积分保持分区一致。
- 抓物：移位、下爪、闭爪、上升、回程、放落、领取；原理观察跟随原速，不提供手动暂停关卡。

## 生命周期

默认自由玩，音效默认关闭。主动开启声音后由 WebAudio 合成，没有外部音频下载。后台暂停与重新进入时间戳处理按各产品现有策略保留。无动作时应停止重绘；退出观察不是重置机械进度，重置要清除旧动作和回调。

时间一致性回归比较相同模拟时间输入；保留安全 dt 上限，因此不能把长时间卡顿或后台暂停解释为墙钟等速。SVG 模型是机械关系示意，不是工程安全系统、真实压力/温度或刚体物理仿真。
