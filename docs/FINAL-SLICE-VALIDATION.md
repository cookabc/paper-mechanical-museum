# 最终切片：十件同一应用

基于第三切片远端 `2d80d2bb2eed8fb47d5eb2bb581856b7553db109`。新增洗衣机和抓娃娃机，十件全部由同一个 Vite 应用真实挂载；没有嵌套站点或 iframe。本报告描述开发候选，不代表合并或生产发布。

## 同域路由

首页 `/#/`；展品分别为 `/#/washer`、`/#/fan`、`/#/claw`、`/#/coffee`、`/#/musicbox`、`/#/vending`、`/#/toaster`、`/#/turntable`、`/#/camera`、`/#/elevator`。首页卡片、推荐作品和场景内馆藏目录均使用这些 hash 路由。旧独立站不在本次代码中自动重定向，未来切换旧入口时必须保留展品 hash，而不只换域名。

## 两种“离开”并不相同

退出原理观察仅收起讲解，不销毁机器，重入保留进度和暂停状态；离开当前展品路由会终止该场景、释放资源，重新进入新建初始状态。后者不会保存半杯、半程或未领取物品。这沿用安全销毁契约，没有增加跨场景持久化。浏览器隐藏/恢复是另一种暂停原因，自动回归验证不追赶后台时间。

## 结构与对照

洗衣机/抓物各保留一个明确的历史渲染适配器，而非把两套核心同名覆盖。它们与另外八件使用同一 SceneContext、ResourceScope、音效服务、原理观察组件及应用路由。机械状态机和 SVG 层次仍由各自真实模型生成。

新增14项真实模型对照/生命周期回归：洗衣装衣、加料、运行、暂停恢复、取衣；抓物落空、四只娃娃抓取/领取、计数、全部阶段和多视角。原源码 fixture 与新模块的状态及实际 SVG 逐字比较。另检查 scope-only 终止、暂停时间不追赶、输入释放、旧 RAF/领取回调失效、snapshot 不可反向改状态和重复销毁。JSDOM 缺失的 getScreenCTM 使用明确布局 stub，不把它当真实浏览器几何测试。

最后两件独立轻量复核也通过：空白拖拽后的 pause / scope-only dispose 释放 capture，旧控制器、属性回调和已捕获 RAF 均不能修改替代 DOM、焦点或共享音效；10张预览独立检查无脚本、事件属性或外部资源。这项独立检查没有冒充浏览器或完整机械流程复验。

最终本地检查：80项 Vitest、ESLint、TypeScript、生产构建全部通过。历史基线测试保留独立运行，不与现代适配回归混称。

## 真实云浏览器

在前台 Chromium 中使用页面实际按钮、模型目标和键盘，不注入模型状态：

- 洗衣机：键盘装衣、加料、选择快洗、完整完成并取回衣篮；第二轮在53%暂停，滚筒缓停至0。退出/重入讲解期间进度保持53%、水位92%、门锁锁定；继续后由当前阶段推进。查看已有内部剖视和打开取衣动作。
- 抓娃娃机：瞄准蓝莓熊，完整下降/夹取/上升/运送/领取，计数1只/1次；下降时退出再进入讲解，动作连续且不重复计数。随后实际按住方向键移到边缘、空格下爪落空，计数保持1只/2次；原有重摆清零为0/0。抓物讲解沿用原速，不新增暂停关卡。
- 全十件两轮跨场景往返；第一轮触发实际动作后离开，包含咖啡装豆、相机快门、投币、吐司装片、风扇电源、音乐盒摇柄、唱片转盘、洗衣装衣及抓物下爪。另在电梯关门36%切走。第二轮检查每件只有一个标题、模型和音效面板，静音默认、讲解收起、scrollTop=0。没有遗留旧场景控件。返回咖啡静止帧计数2→2。
- 最后两件在正常浏览器300%缩放形成的388 CSS像素视口中，document/body scrollWidth 均为388，主操作仍可滚动到达；恢复100%后桌面布局正常。此前八件的流程和窄宽见前两份切片报告。

这些是桌面浏览器窄CSS宽度检查，不是手机设备、触屏或读屏软件实测。没有声称音效经过耳听；声音默认静音，音频资源清理由自动回归验证。也不把抽样动作和逐字渲染对照称作所有视角穷尽验收。

## 产物边界
