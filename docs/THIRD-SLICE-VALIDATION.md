独立审查找到 scope-only 销毁后旧控制器仍能 reset 状态的问题，新增三个实际适配器失败回归，再补 scope.active 终止检查和只读深拷贝 snapshot。独立轻量复验确认旧 pause/reset/resume 不改变状态或共享音效，capture/RAF/timer/listener 全部释放。

## 对照测试

- 直接执行原源码与新模块的同时间线，对照状态、说明、实际 SVG、图层顺序及 mask。包括八音盒正反摇柄/开合盖/停止，唱臂移入/落针/换速/抬针/完整播放自动归位，电梯开关门反转、重复呼叫与队列、到站/重置、多角度和高亮缓存重新投影。
- 旧音符定时声音在暂停/销毁时停止并解绑；恢复不会擅自重开声音。
- 只做 Node SVG 生成相对诊断，不作 FPS 承诺：相同24个旋转姿态、预热后3轮中位数，原源与新模块分别为音乐盒8.51/4.69ms、唱片机7.03/3.48ms、电梯31.11/14.51ms。原源运行在VM对照环境，不能把此数当真实浏览器提速倍数；未见迁移带来的生成耗时退化迹象。
